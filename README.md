# Taskly

A dynamic task management and productivity web application developed during my professional internship at INOVCORP.

## 📖 About the Project

Taskly is a web application designed to help users organize, track, and manage their daily tasks and projects efficiently. The project focuses on providing an intuitive user experience with real-time task updates, categorization, and progress tracking.

The project was developed as part of my professional internship, emphasizing full-stack web development, clean architecture, and responsive user interface design.

## ✨ Features

- 📝 **Task Management:** Create, edit, complete, and delete tasks.
- 🏷️ **Categorization & Tags:** Organize tasks by categories, priorities, or project boards.
- 📅 **Due Dates & Status Tracking:** Monitor pending, in-progress, and completed tasks.
- 👤 **User Authentication:** Secure user accounts with personal task workspaces.
- 🔎 **Filtering & Search:** Easily filter tasks by priority, status, or date.
- 📱 **Responsive Interface:** Smooth and accessible experience across desktop and mobile devices.

## 💻 My Contribution

During the development of Taskly, I was responsible for key aspects of the application, including:

- Creating relational database schemas for users, tasks, and categories.
- Developing reactive and responsive frontend components using Tailwind CSS and JavaScript/Vue.js.
